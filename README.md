# Project Description
> This project is a clone of the popular accommodation booking platform AirBnB. The goal is to understand how to structure a complex web application.

## Tech stack 
- HTML, CSS, JavaScript (React)
- Using figma for UI/UX design

## Color Styles:
- Primary: #FF5A5F
- Secondary: #008489
- Background: #FFFFFF
- Text: #222222
- Secondary Text: #717171

## Typography:
- Primary Font: Circular, Medium (500), 16px
- Headings: Circular, Bold (700), 24px-32px
- Secondary Text: Circular, Book (400), 14px
